实操环境推荐指引与常用操作

本周编程实操题重点考察键盘输入交互、多分支阶梯判断、while/for 循环逻辑和字符串高级处理。推荐通过以下两种方式实操练习：

VSCode（推荐工程化实操）

  • 在工作区新建 Python 脚本文件，例如 task1.py。
  • 快捷键 Ctrl + ` 打开内置终端。
  • 终端输入指令：python task1.py 进行键盘输入交互。
  • 如遇逻辑问题，可设置断点并按 F5 启动单步调试观察变量值变化。

Jupyter Lab / Notebook（推荐探索式验证）

  • 新建 .ipynb 文件，为每道实操题单独建立代码单元格（Cell）。
  • 使用 Shift + Enter 快捷键执行当前单元格代码。
  • 若遇到无限死循环，点击上方工具栏的 ■（中断内核） 强行终止。
  • 对不熟悉的函数可在单元格输入 print? 或 help(str.strip) 调出帮助文档。
